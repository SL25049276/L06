# App Name
Digimon Beat Break Quiz <br>
A small quiz on the Digimon Beat Break anime's Glowing Dawn cast

# Features Highlight
The code is a quiz that uses scroll view to allow you to scroll through the quiz, 
Picker to create a dropdown to select quiz options, <br>
TouchableOpacity to display hints using a Toast popup, <br>
Button to submit your quiz answers using Alert by using setState and useState to calculate the score.

Also used AI to style the app's background color and the rounded containers while I added vector icons from FontFamily6
